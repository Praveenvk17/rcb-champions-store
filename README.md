## 💡 Key Features
* **Dynamic Inventory:** A responsive catalog of 72 products across 6 categories (Bats, Balls, Pads, Gloves, Nets, Kits) with real-time multi-parameter filtering.
* **Persistent Cart System:** Engineered with the Browser LocalStorage API to retain user selections, quantities, and real-time total calculations across sessions.
* **Automated Email Checkout:** Integrated the EmailJS SDK for pure client-side order dispatch, sending instant customized order invoices to customers seamlessly without a backend database.
* **Smart UI Fallbacks:** Built custom dynamic SVG vector generators that act as visual fallbacks to ensure a 0% broken-image experience.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **UI Framework:** Bootstrap 5
* **Storage & APIs:** LocalStorage API, EmailJS SDK
* **Deployment:** GitHub Pages

## 📂 Folder Structure
* `index.html` - Main entry point and UI structure
* `style.css` - Custom styling and responsive design overrides
* `app.js` - Core logic (DOM manipulation, Cart management, EmailJS integration)
* `bats/`, `balls/`, `pads/`, `gloves/`, `nets/`, `kits/` - Organized product image assets

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/YourUsername/rcb-champions-store.git`
2. Open the project folder.
3. Simply double-click `index.html` to open it in your browser (No local server required).
